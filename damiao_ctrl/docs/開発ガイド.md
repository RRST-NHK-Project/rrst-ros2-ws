# Damiaoモータ 開発ガイド

Damiao DM3520(ESC)+ DM2325(モータ)を、ESP32(SOKI基板)経由のCANで動かすための手引きです。
「自分たちでプログラムを書いて、モータを増やして、実戦で使える」ことを目標に書いています。

- 初めての人は **1 → 3 → 4** の順に読んでください。
- モータを増やす時は **5**、困った時は **7** を見てください。

---

## 1. 全体の仕組み

```
 自分のプログラム / PS4ノード          damiao_driver_node           ros2can            ESP32(SOKI基板)        ESC(DM3520)→モータ
 ───────────────────────          ──────────────────          ───────            ─────────────────        ─────────────────
 damiao/motor1/cmd  ──送る──→   指令を24個の数値に詰める  ─→ serial_tx_201 ─→ USB ─→ CANの指令に変換 ─→ CAN ─→ 指令どおり回る
 damiao/motor1/state ←受け取る─  24個の数値から取り出す   ←─ serial_rx_201 ←─ USB ←─ 返事を数値に変換 ←─ CAN ←─ 状態・位置を返す
```

| 部品 | 役割 | どこにある |
|---|---|---|
| 自分のプログラム | 「どう動かすか」を決めて cmd を送る | `damiao_ctrl/src/`(お手本: `example_motor_control.cpp`) |
| `ps4_teleop_node` | PS4コントローラで動かす | `damiao_ctrl/src/ps4_teleop_node.cpp` |
| `damiao_driver_node` | cmd/state と、ESP32とやり取りする24個の数値を変換する。安全の見張りもする | `damiao_ctrl/src/damiao_driver_node.cpp` |
| `ros2can` | PCとESP32をUSBでつなぐ(チーム共通ツール) | `~/ros2_ws/src/ros2can` |
| ESP32ファームウェア | 24個の数値と、DamiaoのCAN通信を変換する。安全の見張りもする | `ros2can/firmware/xiao-esp32-s3_can2io/src/damiao.cpp` |
| ESC(DM3520) | モータの中のコンピュータ。速度や角度の制御そのものはここがやる | — |

**ポイント:** 速度や角度の細かい制御(PID)はESCが自分でやります。PC側は「この速度で」「この角度へ」と指令するだけです。

### ESP32側(`~/ros2_ws/src/ros2can/firmware/xiao-esp32-s3_can2io/src/`)

| ファイル | 中身 | よく変えるか |
|---|---|---|
| `config.hpp` | `DEVICE_ID`、モード、**`DAMIAO_MOTORS`(モータの表)**、タイムアウト | ★モータを増やす時 |

## 3. 動かし方

**ターミナルを3つ開き、どれでも最初に `export ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST` をする**
(しないと、同じWi-Fiの他のPCのノードとつながってしまう。7章参照)。

```bash
# ターミナル1: PC⇔ESP32の通信
export ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST && source ~/ros2_ws/install/setup.bash && ros2 run ros2can ros2can --nogui
```

```bash
# ターミナル2: 駆動ノード + PS4(PS4を使わないなら use_joy:=false)
export ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST && source ~/ros2_ws/install/setup.bash && ros2 launch damiao_ctrl damiao_ctrl.launch.py use_joy:=true
```

```bash
# ターミナル3: 回転数・位置の表示
export ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST && source ~/ros2_ws/install/setup.bash && ros2 run damiao_ctrl motor_monitor --ros-args --params-file ~/ros2_ws/install/damiao_ctrl/share/damiao_ctrl/config/damiao_ctrl.yaml
```

- 止める時は **Ctrl+C**(2 → 1 の順)。**Ctrl+Z は止まらずに「一時停止」で残る**ので使わない。
- コードや設定を変えたら、`cd ~/ros2_ws && colcon build --packages-select damiao_ctrl` してから起動し直す。
- PS4: **R1を押している間だけ**動く。左スティック上下=モータ1の速度、右スティック=モータ2の向き(角度)。
  Options=非常停止(R1を押し直すと再開)、△=モータ2の「今の向き」をスティック上にする。

## 4. 自分のプログラムからモータを動かす

### 4.1 cmd と state の決まり

どちらも `std_msgs/msg/Float32MultiArray` です。モータN番のトピックは `damiao/motorN/cmd` と `damiao/motorN/state`。

**cmd(自分のプログラム → 駆動ノード)** `data = [モード, 目標, 速さの上限]`

| 送る値 | 意味 |
|---|---|
| `[-1, 0, 0]` | 脱力(止める。力を抜く) |
| `[0, 速度, 0]` | **速度制御**。速度は rad/s(出力軸)。例: `[0, 2.0, 0]` = 2rad/s で回る |
| `[1, 角度, 速さ]` | **角度制御**。その角度[rad]へ、速さ[rad/s]以下で回って止まる。例: `[1, 1.57, 3.0]` |

- **50回/秒くらいで送り続ける**こと。0.5秒届かないと、駆動ノードがそのモータを自動で脱力させます(プログラムが落ちた時の安全のため)。
- 速度・速さは ±45.6rad/s(435rpm)に制限されます(実機の最高48rad/sの95%)。
- 単位の換算: rpm = rad/s × 9.55、1回転 = 6.283rad、90° = 1.571rad。

**state(駆動ノード → 自分のプログラム)** `data = [位置, 速度, トルク, 状態, 帰還OK, 内部の位置]`

| 番号 | 中身 | 注意 |
|---|---|---|
| 0 | 位置[rad] | ±12.5radで一周して反対側に飛ぶ |
| 1 | 速度[rad/s] | 約0.1rad/s刻み。止まっていても ±0.05 くらい出る |
| 2 | トルク[N・m] | |
| 3 | 状態 | 0=脱力 1=有効 それ以外=故障(13=通信喪失) |
| 4 | 帰還OK | 1=モータから返事が来ている、0=来ていない |
| 5 | 内部の位置[rad] | モータが内部で数えている位置。±12radを超えていると**角度制御は使えない**(7章) |

### 4.2 お手本 `example_motor_control` を読む・書き換える

`src/example_motor_control.cpp` は「モータ1を速度制御で回して止め、モータ2を角度制御で90°向けて戻す」プログラムです。

```bash
ros2 run damiao_ctrl example_motor_control
```

動きを変えるには、ファイルの中の **`run_step()`(【ここを書き換える】の所)だけ**を変えます。
`t` は動き始めてからの秒数です。

```cpp
void run_step(double t)
{
  if (t < 3.0) {
    m1_.set_velocity(2.0);                      // 0〜3秒: モータ1を2rad/sで
  } else if (t < 6.0) {
    m1_.set_velocity(-1.0);                     // 3〜6秒: モータ1を逆向きに1rad/sで
    m2_.set_angle(start_angle2_ + 3.14, 2.0);   //        モータ2を始めの向きから半回転へ
  } else {
    finish();                                   // 2台とも脱力して終わる
  }
}
```
(`start_angle2_` はモータ2の始めの向き。角度は±12radの範囲に収まるようにすること)

使える命令:

| 命令 | 意味 |
|---|---|
| `m1_.set_velocity(速度)` | 速度制御 [rad/s] |
| `m1_.set_angle(角度, 速さ)` | 角度制御 [rad, rad/s] |
| `m1_.set_disable()` | 脱力 |
| `m1_.position()` / `velocity()` / `torque()` | 今の値を読む |
| `finish()` | 全部脱力して終わる |

お手本は「始める前に返事が来ているか確認」「故障したら全部止める」「Ctrl+Cでも脱力を送る」を全部やっています。
新しく作る時も、これをコピーして `run_step()` を書き換えるのが一番安全です。

### 4.3 新しいノードを作る手順

1. お手本をコピーする
   ```bash
   cp ~/ros2_ws/src/damiao_ctrl/src/example_motor_control.cpp ~/ros2_ws/src/damiao_ctrl/src/my_control.cpp
   ```
2. `my_control.cpp` の中の `example_motor_control` / `ExampleMotorControl` を自分の名前に変え、`run_step()` を書き換える。
3. `CMakeLists.txt` に追加する(`example_motor_control` の4つのブロックをまねて、`install(TARGETS …)` にも名前を足す)。
4. ビルドして実行
   ```bash
   cd ~/ros2_ws && colcon build --packages-select damiao_ctrl && source install/setup.bash && ros2 run damiao_ctrl my_control
   ```

### 4.4 実機なしで試す(`fake_esp32.py`)

ros2canの代わりに `fake_esp32.py` を起動すると、ESP32とモータのふりをしてくれます。
**新しいプログラムは、まずこれで動きを確かめてから実機で試す**のがおすすめです。

```bash
# ターミナル1(ros2canの代わり。本物のros2canと同時に起動しないこと)
export ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST && source ~/ros2_ws/install/setup.bash && ros2 run damiao_ctrl fake_esp32.py
```

ターミナル2・3は3章と同じ(駆動ノード、表示)。そのあと自分のプログラムを起動します。
ふりなので、重さ・摩擦・故障などは再現しません。最後は必ず実機で確かめてください。

### 4.5 Pythonで書く場合(最小の例)

```python
import rclpy
from std_msgs.msg import Float32MultiArray

rclpy.init()
node = rclpy.create_node("my_python_control")
pub = node.create_publisher(Float32MultiArray, "damiao/motor1/cmd", 10)

def send(data):
    msg = Float32MultiArray(); msg.data = [float(x) for x in data]; pub.publish(msg)

try:
    for _ in range(150):            # 3秒間(50回/秒)、2rad/sで回す
        send([0, 2.0, 0]); rclpy.spin_once(node, timeout_sec=0.02)
finally:
    for _ in range(20):             # 必ず脱力を送ってから終わる
        send([-1, 0, 0]); rclpy.spin_once(node, timeout_sec=0.02)
    rclpy.shutdown()
```

## 5. モータを増やす

### 5.1 決まり(ID・番号の付け方)

1枚のESP32につなげるのは**最大4台**です(PCとやり取りする数値が24個で、1台に6個使うため)。

| モータ | ESC_ID(指令を受けるID) | MST_ID(返事を送るID) | つなぐESP32(DEVICE_ID) | トピック |
|---|---|---|---|---|
| 1 | 0x01 | 0x000(工場出荷のまま) | 201 | damiao/motor1 |
| 2 | 0x02 | 0x012 | 201 | damiao/motor2 |
| 3 | 0x03 | 0x013 | 201 | damiao/motor3 |
| 4 | 0x04 | 0x014 | 201 | damiao/motor4 |
| 5 | 0x05 | 0x015 | 204(2枚目) | damiao/motor5 |
| 6 | 0x06 | 0x016 | 204(2枚目) | damiao/motor6 |

- ESC_ID・MST_IDは**ESCごとに全部ちがう番号**にする(同じだと指令や返事がぶつかる)。
- 新しいESCは工場出荷時、どれも ESC_ID=1, MST_ID=0x000 なので、**つなぐ前に必ず書き換える**。
- DEVICE_IDは他のモードと重ならない番号にする(202=RobStride、203=GM6020 で使用中)。

### 5.2 4台まで(ESP32は1枚のまま)の手順

例: モータ3を足す。

1. **新しいESCのIDを書き換える**(ESCだけを達妙USB-CANにつなぎ、ros2canは止めておく)
   ```bash
   python3 ~/ros2_ws/src/damiao_ctrl/scripts/dm_usbcan_param.py scan
   ```
   ```bash
   python3 ~/ros2_ws/src/damiao_ctrl/scripts/dm_usbcan_param.py set-id --id 1 --new-id 3 --new-mst 0x13
   ```
   ESCの電源を入れ直してから、もう一度 `scan` して「ESC_ID 3: 応答あり(返信CAN ID 0x013)」と出ればOK。
   ほかの設定を見る時は `read --id 3`。
2. **配線**: CANH同士・CANL同士をまとめてSOKI基板のCAN1へ。電源OFFでCANH-CANL間を測り、約60Ω(両端に120Ω)が理想。
3. **ESP32の設定** `config.hpp` の `DAMIAO_MOTORS` に1行足す
   ```cpp
   #define DAMIAO_MOTORS {                                                    \
       {0x01, 0x000}, /* モータ1 */                                         \
       {0x02, 0x012}, /* モータ2 */                                         \
       {0x03, 0x013}, /* モータ3: 〇〇用 */                                 \
   }
   ```
4. **ESP32に書き込む**(ros2canは止めておく)。
   書き込む前に、`config.hpp` の上の方が **`#define MODE_DAMIAO`(ほかのMODE_はコメントアウト)と
   `#define DEVICE_ID 201`** になっているか確認する(RobStrideなど別のモータ用になっていることがある)。
   ```bash
   cd ~/ros2_ws/src/ros2can/firmware/xiao-esp32-s3_can2io && ~/.platformio/penv/bin/pio run -t upload --upload-port /dev/ttyACM0
   ```
5. **PC側の設定** `config/damiao_ctrl.yaml` の `motor_count: 3` にして、ビルド
   ```bash
   cd ~/ros2_ws && colcon build --packages-select damiao_ctrl
   ```
6. **PS4でも動かすなら** `ps4_teleop_node` の配列に足す(同じ長さにする)
   ```yaml
   motor_numbers: [1, 2, 3]
   control_modes: ["velocity", "angle", "velocity"]
   stick_y_axes: [1, 4, 1]     # モータ3も左スティック上下で(モータ1と一緒に動く)
   stick_x_axes: [0, 3, 0]
   invert_axes: [false, false, false]
   ```
7. **確認**: 3章の手順で起動し、表示(ターミナル3)で3台とも「帰還 OK」になっていること。
   最初は `ros2 topic pub` などで低速から試す。

### 5.3 5台以上(ESP32を増やす)

1. 2枚目のSOKI基板(ESP32)を用意し、`config.hpp` の **`DEVICE_ID` を 204** にし、`DAMIAO_MOTORS` に2枚目につなぐモータの行を書いて書き込む。
   (1枚目用に戻す時は `DEVICE_ID 201` と1枚目の表に戻すこと。基板ごとに書き込む内容が違うので、書き込む前に必ず確認する)
2. ros2canは1つ起動すればよい(USBにつながったESP32を全部自動で見つける。`devices: 2` と出る)。
3. 2枚目用の駆動ノードを**別の名前で**もう1つ起動する(例: 2枚目に2台、モータ5・6として使う)
   ```bash
   ros2 run damiao_ctrl damiao_driver_node --ros-args -r __node:=damiao_driver_node_2 -p device_id:=204 -p motor_count:=2 -p first_motor_number:=5
   ```
   これで `damiao/motor5`、`damiao/motor6` が使えるようになる。
4. 表示も5・6番を見るなら `motor_monitor` に `-p "motor_numbers:=[1,2,5,6]"` を付ける。

## 6. 安全の仕組み(何が起きたら、何が止めるか)

| 起きたこと | 止める仕組み | 止まるまで |
|---|---|---|
| R1を離した・Optionsを押した | PS4ノード | すぐ |
| PS4の入力が途絶えた(USB抜け等) | PS4ノード | 0.5秒 |
| 自分のプログラム・PS4ノードが落ちた | 駆動ノード(cmdが0.5秒来ない) | 約0.7秒 |
| 駆動ノードをCtrl+C | 駆動ノードが終了前に脱力を送る | 約0.2秒 |
| ros2canが落ちた・USBが抜けた | ESP32(PCの指令が0.3秒来ない) | 0.3秒 |
| ESP32が固まった・CAN線が抜けた | モータ自身(0.1秒指令が来ない→状態13) | 0.1秒 |
| 内部の位置が±12radを超えたモータに角度指令 | ESP32とPS4ノードが角度制御を拒否 | 有効にしない |
| 角度制御で指令より0.5rad以上大きく回った | PS4ノード | すぐ |

**守ること**
- 動かす前に、モータを固定し、回転部に手や物が近づかないようにする。
- 最初は低速から。新しいプログラムは `fake_esp32.py` で確かめてから。
- 止める時は Ctrl+C。万一の時はバッテリーのスイッチを切る。
- 駆動ノード(同じdevice_id)を2つ起動しない。

## 7. 困った時(これまでに実際に起きたこと)

| 症状 | 原因 | 対処 |
|---|---|---|
| 返事の回数が増えない・state が来ない | モータの電源(バッテリー)が入っていない | 電源を入れる。ESCのLEDを確認 |
| R1を押しても0.1秒ごとに止まる/動くを繰り返す | 同じWi-Fiの他のPCの joy_node が混ざっている | 全ターミナルで `export ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST` |
| 新しく起動したノードから他のノードが見えない | PCがスリープした・Wi-Fiがつなぎ直された / Ctrl+Zで一時停止したノードが残っている | 全部止めて起動し直す。一時停止したものは `kill -9 番号`(`pgrep -af damiao_ctrl` で番号を調べる) |
| ゆっくり回すと位置の数値が変わらない(実際は回っている)・角度制御で勝手に回る | 速度制御で何百rad回して、モータ内部の位置が大きくなった | **モータの電源を入れ直す**(内部の位置が0に戻る)。表示の「内部」で確認できる |
| 角度制御が有効にならない(ログに「内部の位置が…」) | 上と同じ。安全のため拒否している | 電源を入れ直す |
| 2台目のESCが反応しない | ESC_IDが1のまま(1台目とぶつかる) | `dm_usbcan_param.py` でIDを書き換える(5.2) |
| ESP32に書き込めない(port is busy) | ros2canなどがポートを使っている | ros2canをCtrl+Cで止める |
| 速度が48rad/sより上がらない | ESCの最高速度の設定(1200=モータ軸)÷減速比25 | 仕様。上限は45.6rad/sにしてある |
| 状態13(通信喪失)で止まった | CAN線が抜けた・ESP32が止まった | 原因を直し、一度脱力([-1,0,0])を送ってから指令し直す |
| `No space left on device` | ディスクがいっぱい | 不要なキャッシュ・古いログを消す(`~/.ros/log` など) |

## 8. 用語

| 用語 | 意味 |
|---|---|
| ESC | モータを回す回路(DM3520)。速度・角度の制御はここがやる |
| CAN | ESCとESP32をつなぐ通信。2本の線(CANH・CANL)に何台もぶら下げられる |
| 終端抵抗 | CAN線の両端に付ける120Ω。無いと通信が乱れる |
| ESC_ID / MST_ID | ESCが指令を受け取るID / 返事を送るID |
| DEVICE_ID | ESP32の番号(ros2canのトピック名 serial_tx_201 の 201) |
| レジスタ | ESCの設定値の入れ物(番号RIDで指定。例: 10=制御モード、80=内部の位置) |
| 速度制御(VEL) | 「この速さで回れ」 |
| 角度制御(POS_VEL) | 「この角度へ、この速さ以下で回って止まれ」 |
| 脱力 / 有効 | 力を抜いた状態(手で回せる) / 指令どおりに力を出す状態 |
| rad, rad/s | 角度の単位(1回転=6.283rad)、速さの単位(rpm = rad/s × 9.55) |
